AuxCam 电脑端（Windows）使用说明
====================================

1. 电脑上先打开 OBS，点"启动虚拟摄像头"。
2. 手机打开 AuxCam。
3. 打开本软件 AuxCamPC.exe：
   - 摄像头：选 OBS Virtual Camera
   - 编码：选"自动"（有显卡会自动用显卡编码）
   - 画质：默认 15（1080 很清楚，手机也解得动），不用改
   - 连接方式：
       USB 数据线：手机插电脑，需要装 iTunes 或 Apple Devices（微软商店可下）
       网络（WiFi / 有线网卡）：手机 AuxCam 设置里打开"允许网络连接"，把显示的地址填到"手机 IP"
4. 点"开始推流"，状态变绿 = 正常。

注意：
- 走网络时手机和电脑要连同一个路由器。用 WiFi 的话最好是 5G 频段、电脑插网线、手机离路由器近一点。
- 本软件发的是"解码快"的视频格式（CAVLC），手机不用费力也能稳 30 帧。
